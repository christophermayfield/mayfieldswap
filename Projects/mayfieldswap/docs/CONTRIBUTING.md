# Contributing to MayfieldSwap

We welcome contributions to MayfieldSwap! This document provides guidelines for contributing to the project.

## 🚀 Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/YOUR_USERNAME/mayfieldswap.git`
3. Install dependencies: `npm run setup`
4. Create a feature branch: `git checkout -b feature/your-feature-name`

## 📝 Development Process

### Smart Contracts
- Follow Solidity best practices
- Add comprehensive tests for new features
- Ensure all tests pass: `npm test`
- Follow the existing code style

### Frontend
- Use TypeScript for type safety
- Follow React/Next.js best practices
- Ensure components are responsive
- Add proper error handling

### Testing
- Write tests for new features
- Maintain 100% test coverage for critical paths
- Test on local Hardhat network before submitting

## 🔐 Security

- Never commit private keys or sensitive data
- Use proper access controls in smart contracts
- Follow DeFi security best practices
- Report security issues privately

## 📋 Pull Request Process

1. Update documentation for any new features
2. Add tests for new functionality
3. Ensure all tests pass
4. Update the README if needed
5. Submit a clear pull request description

## 🎯 Areas for Contribution

- **Smart Contract Optimization**: Gas optimization improvements
- **Frontend Features**: New UI components, better UX
- **Testing**: Additional test cases, edge case coverage
- **Documentation**: Tutorials, guides, API documentation
- **Security**: Security audits, vulnerability fixes

## 📞 Questions?

Open an issue for discussion before starting major changes.

Thank you for contributing to MayfieldSwap! 🍣
